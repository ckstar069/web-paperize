# web-paperize V0.1 范围定义

> 目标：在基准网页上，把「当前页 → 矢量 PDF」的质量做到与 Page to PDF 基本同档。
> 验收不设"能导出 PDF"这种低门槛——以 A/B benchmark 为准（§4）。

## 1. 功能清单

### 1.1 做（In Scope）

| # | 功能 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 1 | 当前标签页 → 矢量 PDF | — | 唯一入口：popup 按钮 |
| 2 | 纸张 | A4 | A4 / Letter 二选一（V0.1 先这两种） |
| 3 | 方向 | Portrait | Portrait / Landscape / **Auto**（按内容宽高比 >1.2 自动横版） |
| 4 | 边距 | Slim(0.2in) | None/Slim(0.2)/Normal(0.4)/Wide(0.8)；预期物理打印时建议 Normal 以上 |
| 5 | Screen CSS 渲染 | 开 | `setEmulatedMedia('screen')` + reduced-motion，核心卖点 |
| 6 | 背景打印 | 开 | `printBackground: true` |
| 7 | 宽度自适应 | 开 | 桌面宽页缩放进可打印宽度（scale clamp [0.1,1]） |
| 8 | lazy-load 预滚动 | 开 | 滚动熔断：400 步 / 高度 4 倍暴涨 / 200000px |
| 9 | 字体/图片等待 | 开 | fonts.ready 3s 竞速；逐图 6s 超时 |
| 10 | 去杂物 | 开 | 噪声词 + 遮罩覆盖率判定 + fixed/sticky 改 static |
| 11 | 内部滚动展开 | 开 | 跳过 >20000px 容器 |
| 12 | `<details>` 展开 | 开 | — |
| 13 | 分页友好 | 开 | break-inside avoid / thead 跨页重复 |
| 14 | 导出后页面完整恢复 | 必须 | undo log 逆序 + 空 style 属性清除 |
| 15 | 文件名模板 | `{title}` | 宏见 ARCHITECTURE §3.5 |
| 16 | 进度反馈 | — | badge + popup 进度 |
| 17 | 标签页缩放校正 | 待实测定稿 | 捕获时记录 zoom；width 策略（是否/如何做 viewport 覆盖）由 §4 的 zoom 四组实验决定（ARCHITECTURE §1 的 viewportOverride 实验开关，默认关） |
| 18 | 本地运行 | 必须 | 无网络请求/遥测/上传 |

### 1.2 不做（Out of Scope，按版本递进）

- **V0.2**：Snapshot 像素模式（Canvas/WebGL 页面）、元素选择器导出、文字选区导出、单张连续长页、页眉/页脚、A3/A5/Legal/Tabloid/自定义纸张、HUD 页内进度药丸、右键菜单、快捷键。
- **V0.3**：网站级 preset（chatgpt.com / github.com / 知乎…）、Readability Article Mode、批量导出/后台标签页、PDF 内置预览（PDF.js）。
- **明确不做**：html2canvas/jsPDF 重绘路线；无限流页面完整加载（400 步熔断即止，超出部分不强求）；账号/云/服务器。

## 2. 交互规格（popup）

```
┌──────────────────────────┐
│      Export PDF          │
│                          │
│  Paper    [A4     ▾]    │
│  Layout   [Auto    ▾]    │
│  Margin   [Slim   ▾]    │
│                          │
│    [  Save as PDF  ]     │
│                          │
│  （进度条 / 结果 / 错误）  │
└──────────────────────────┘
```

- debugger 为 manifest **required** 权限（Chrome 规范不允许 optional，见 ASSESSMENT §1.9），安装时声明；popup 无权限请求流程。
- 受限页面（chrome:// 等）：按钮禁用 + 一行解释。
- 忙碌（同 tab 正在导出）：按钮禁用 + "Exporting…"。

## 3. 质量红线（实现层面的验收）

1. debugger **任何**异常路径都必须 detach（try/finally + 引用计数）。
2. 恢复契约：插件**主动施加**的 DOM/style/attribute/scroll/details 修改必须全部恢复（undo log 覆盖所有变更）；预滚动触发的页面自身 JS 副作用（lazy 已加载、infinite scroll 增长等）不承诺回滚。
3. 打印前 viewport 已按文档全高 × zoom 覆盖（顺序：prepare → 测量 → viewport → print）。
4. 大 PDF（>10 MB 文本模式少见，但 5 万字长文档需验证）走流式 + blob URL，不崩。
5. 每次 printToPDF 前后 `setEmulatedMedia` 状态必复原。
6. debugger attach 失败 / 捕获中被外部 detach（含用户点掉调试条）：分类文案，不崩、不留半状态。
7. 纯静态加载：无 npm install、无 build，`Load unpacked` 即用。

## 4. A/B Benchmark 验收（对照 Page to PDF）

确定性本地基准（每次回归的第一站）：

`tests/fixtures/benchmark.html` —— 离线、无网络依赖，一页覆盖：sticky header、fixed 悬浮按钮、可关闭 overlay、折叠 `<details>`、内部滚动容器、lazy 图片（`loading=lazy` 与 `data-src` 惯例各一）、宽 table、宽 `pre` 代码块、中文标题/正文/中英混排、背景色与渐变、锚点与外部链接、足够触发分页的总高度。

zoom / viewport 策略实验（决定 §1.1 第 17 项的最终实现）：

| 场景 | 记录 |
| --- | --- |
| 普通页 @100% zoom | contentWidth、zoom、打印后内容宽度 |
| 普通页 @150% zoom | 同上 |
| 宽 overflow 页 @100% | 同上 |
| 宽 overflow 页 @150% | 同上 |

结果存 `docs/benchmark/`，据此定稿 width 策略。

真实网站矩阵（产品级测试，保留；覆盖我们已知的全部难点类型）：

| 类别 | 示例 | 考察点 |
| --- | --- | --- |
| 技术文档 | MDN 长文档、某 library 文档站 | 代码块/pre、侧栏 sticky、内部滚动 |
| 代码托管 | GitHub README + 源码页 | 长表格、行内代码、宽 diff |
| 中文社区 | 知乎回答/专栏 | 中文字体、浮动操作栏、lazy 图 |
| AI 对话 | ChatGPT 长会话 | 无限流熔断、markdown 代码块、sticky 头部 |
| 新闻/杂志 | 带 lazy 大图的长文 | 图片完整、去 cookie 墙/ newsletter 弹层 |
| 嵌套滚动 | 有 inner scroller 的后台页 | 展开后不截断 |
| 缩放干扰 | 手动把标签页调到 150% 再导出 | 右侧不截断（zoom 校正） |

逐页对照检查项：

```
□ 内容完整（无空白图、无缺失段落）
□ 页面宽度利用一致（无右侧截断、无异常缩放）
□ 字体一致（含中文、等宽代码字体）
□ 背景颜色/图片保留
□ 无重复 sticky header（每页盖章）
□ 内部滚动内容已展开、未截断
□ 分页处无"切半行/切半图"（分页友好 CSS 生效）
□ 文字可选择、可搜索
□ 链接可点击
□ 导出后原网页完全恢复（滚动位置、折叠状态、弹层）
□ 文件体积合理（同页与 Page to PDF 同数量级）
```

**通过标准**：矩阵 7 类页面全部导出成功且每页 ≥9/11 项通过；任何"内容缺失/恢复失败"类缺陷为零容忍。
